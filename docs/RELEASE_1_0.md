## Practical limits

The model initially wrote past a requested stopping point; the latest-only replacement corrected it. Even after stronger instructions, one compressed chapter summary overstated a suspicion, and an advisory review inferred an access requirement that the prose had not established. Source validation guarantees quoted provenance, not semantic correctness. Review can miss contradictions or suggest false positives; it never silently rewrites accepted material. Inspect sources and correct current records as needed.

The live novel used short acceptance targets to exercise more transitions. It verifies this pipeline and fixture, not full-novel recall, every provider/workflow or a guarantee of literary quality. Default passage/chapter targets remain editable. Text and ComfyUI services, models and workflow-specific nodes must already be installed/running. Save migrations and backward compatibility are not promised during this development period.

The source distributable is built locally with `npm run release`. It contains application source, the production build, documentation, notices and supplied workflows; personal databases, images, connection overrides, API keys, installed dependencies and reference checkouts are excluded. Install dependencies with `npm ci` in an extracted copy. Its package acceptance script checks the SHA-256 and excluded secrets, then boots the extracted production app with a fresh library using the already installed lock-matched dependencies. The separate production-only distribution is described below.
