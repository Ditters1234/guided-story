## After 1.0

1. Prioritize [context scoping and token efficiency](CONTEXT_SCOPING.md): measure stages, distinguish active/mentioned entities, constrain inventory expansion and scope extraction with full authoritative validation.
2. Evaluate continuity, character voice and sustained stories against the baseline and user feedback. Defer retrieval infrastructure or automatic review calls until observed misses justify them; current release checks do not guarantee model inferences or literary choices.
3. Setup portability and nested inventories are implemented. Optional image features, richer maps/capacity and currency accounts remain lower priority. The current Krea 2/Sickollie workflow does not require reference images.
